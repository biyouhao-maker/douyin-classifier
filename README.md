# 抖音收藏分类助手（浏览器扩展）

自动采集你在 **抖音网页版** 点赞 ❤ 和收藏 ★ 的视频，按关键词规则（或可选的 AI）自动分类，
在分类看板中浏览、搜索、手动调整，并支持导出 CSV / JSON / HTML。

所有数据只保存在你自己的浏览器里，不上传任何服务器。

---

## 一、安装（Chrome / Edge 通用，约 1 分钟）

1. 打开浏览器的扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角（Edge 在左侧栏）的 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**，选择本文件夹 `douyin-classifier`。
4. （建议）点击浏览器工具栏的拼图图标 🧩，把「抖音收藏分类助手」固定到工具栏。

## 二、使用（三步）

1. 打开 [www.douyin.com](https://www.douyin.com) 并 **登录**，进入「我的主页」。
2. 点击页面 **右下角的红色悬浮球「分」**，在面板里点 **「一键采集（喜欢 + 收藏）」**。
   插件会自动滚动页面逐条抓取；采集完「喜欢」会自动跳到「收藏」继续，期间请不要切换页面。
3. 采集完成后自动打开 **分类看板**：
   - 左侧：按分类筛选（含「未分类」）；
   - 卡片：显示封面、标题、作者、来源（❤/★），下拉框可手动改分类，「×」可删除；
   - 顶部：搜索、按来源筛选、排序、**按规则重新分类**、**AI 智能分类**、导出按钮。

以后新增了点赞/收藏，再点一次采集即可 —— 已采集过的视频自动去重，只会补充新视频。
同一视频既点赞又收藏时，会同时带上两个来源标记。

## 三、分类规则（设置页）

工具栏图标 → 「分类规则与设置」，内置 13 个常用分类（美食、旅行、知识、音乐、影视、搞笑、
生活、科技、健身、宠物、穿搭、三农、情感），每条规则 = 分类名 + 关键词列表 +
颜色。视频 **标题或作者名** 包含任一关键词即归入该分类，按列表从上到下先命中先归类。

- 「＋ 添加分类」：自定义你自己的分类（比如「英语学习」「装修记录」）；
- 「保存规则并重新分类」：保存后立即按新规则重跑（手动指定的分类不受影响）。

## 四、AI 智能分类（可选）

关键词规则覆盖不到的视频，可以交给大模型归类。需要任意 **OpenAI 兼容接口**
（DeepSeek、智谱、通义或各类中转站均可）：

1. 设置页 →「AI 智能分类」→ 勾选启用；
2. 填写接口地址（如 `https://api.deepseek.com/v1`）、API Key、模型名；
3. 点 **「① 授权网络访问」**（浏览器会弹权限确认，这是插件请求 API 必需的）；
4. 点 **「② 测试连接」** 确认可用 → 保存；
5. 回到分类看板，点 **「AI 智能分类」**，它会只处理「未分类」的视频。

API Key 仅存储在本机浏览器（`chrome.storage.local`），不会发往除你配置的接口以外的任何地方。

## 五、数据与备份

- 数据保存在浏览器本地（`chrome.storage.local`），卸载扩展会清空；
- 设置页可 **导出全部数据（JSON 备份）** / **导入备份**；
- 看板支持导出：
  - **CSV**：可直接用 Excel / WPS 打开（UTF-8 BOM，不乱码）；
  - **HTML**：生成一个按分类分组的静态网页，可分享、可离线查看；
  - **JSON**：完整结构化数据。

## 六、常见问题

| 问题 | 说明 |
| --- | --- |
| 采集到 0 条 | 请确认已登录、当前停留在「喜欢」或「收藏」标签页；刚安装扩展后先刷新一次抖音页面 |
| 悬浮球没出现 | 刷新抖音页面；或点工具栏图标 → 「在本页打开助手面板」 |
| 封面不显示 | 抖音 CDN 偶尔防盗链，不影响链接和分类，重新导出或稍后再看 |
| 抖音改版后抓不到 | 插件通过页面里的视频链接 + 标题节点提取，抖音大改版后可能需要更新选择器 |
| 只想要其中一部分分类 | 在设置页删掉不要的规则即可，保存时会自动重新归类 |

## 七、文件结构

```
douyin-classifier/
├── manifest.json          # 扩展清单 (Manifest V3)
├── background.js          # 后台：负责打开新标签页
├── lib/common.js          # 共享：存储层、默认规则、分类与导出逻辑
├── content/content.js     # 抖音页面内：悬浮球 + 自动滚动采集（Shadow DOM）
├── popup/                 # 工具栏弹窗：统计与快捷入口
├── dashboard/             # 分类看板
├── options/               # 设置页：规则管理 / AI 配置 / 数据管理
└── icons/                 # 图标
```
